# 游戏机制

## 内核

充能条：每一帧（满足一定条件时）充能减少 dt，归零时触发效果。归零定义为达到非正值。  
正充能条：每一帧（满足一定条件时）充能*增加* dt，*达到特定值*时触发效果。

### DAS

在：按下单格移动键时 触发。若方向不同，改变方向，将 DAS 充能条补至 ASD。  
在：按下移动到底键时 触发。若方向不同，将 DAS 充能条补至 ASD，**不改变方向。**
在：当前方向的单格移动键松开时 触发。若对向单格移动键按下，改变方向并将 DAS 充能条补至 ASD；否则清除方向。

充能条：充能条归零且存在方向时，增加 ASP，并触发移动。若当前方块不存在，则冻结至 0。若 ASP 为零，改为触发移动到底。

> 代码中相关变量使用旧名称 DAS、ARR，分别等价于 ASD、ASP。

### DCD

在：按下旋转键、硬降键时；方块自动锁定时 触发。将 DCD 充能条补满。

充能条：每一逻辑帧，优先消耗 DCD 充能条，之后消耗 DAS 充能条。

### ARE

在：方块锁定时 触发。将 ARE 充能条增加 ARE 值。  
在：触发消行函数且行数非零时 触发。将 ARE 充能条增加 ARE on clear 值 + ARE per line 值 * 行数。

充能条：当前方块不存在时消耗。归零时，生成方块并结算 IXS。

### Soft Drop

在：按下软降键时 触发。若未开始软降，将 SD DAS 充能条补至 SD ASD。  
在：软降键松开时 触发。结束软降。

充能条：充能条归零且正在软降时，增加 SD ASP，并触发软降。若当前方块不存在，则冻结至 0。若 SD ASP 为零，改为触发瞬降。

> 瞬降键不影响软降状态。

### 重力

在：硬降或自动锁定时 触发。重置充能条。

重力值为下降一格所需要的毫秒数。1G 对应 16+2/3 ms。

正充能条：充能条达到重力值时，归零，并触发软降。若重力值为 0，改为触发瞬降。

### 锁定延迟、锁延刷新

在：触底且移动、旋转成功时；不触底且当前块旋转至少第五次时 触发。刷新次数 -1，开始计算锁延。  
在：触底时 触发。开始计算锁延。  
在：硬降或自动锁定时 触发。重置充能条，补满刷新次数。  
在：暂存时 触发。补充至多(暂存补充次数)次刷新次数，不超过上限。

正充能条：当前方块存在且(触底或**刷新次数为 0 且开始计算锁延**)时计数。充能条达到锁延值时，归零，触发瞬降并自动锁定。

> 根据以上逻辑，在刷新次数耗尽时，即使未触底也可能自动锁定。这是为了防止不触底无限旋转。

### 按键

按键与操作之间可以一对多也可以多对一。多对一时，该操作键被视为按下，当且仅当至少一个按键被按下。

### IXS

分为 IRS、IHS、IMS。模式为：无、Tap、Hold，IMS 不支持 Tap 模式。  
结算顺序为 IHS -> IRS -> IMS。

Tap：ARE 期间，记录按下的最后一个此类键。出块后，立即执行该键对应操作。  
Hold：出块时，检测此类键按下状态。若此类键间未冲突，执行对应操作，否则什么也不做。

IRS：对应三种旋转键。至少有两种按下被视为冲突。  
IHS：对应暂存键。  
IMS：对应四种移动键。移动到底键、单点移动键分别按此顺序结算，均被按下视为冲突。

IMS 单点触发时，若同时保有 DAS 充能条，将其补至 ASP（除非原本更大）。

### 暂存

若未开启无限暂存，硬降或自动锁定之前只得暂存至多一次。

暂存时，将当前方块放入暂存槽末尾。若暂存槽已满，取出暂存槽开头的方块，否则生成下一个方块。  
暂存方块时，其方向重置。

### 结算顺序

每一逻辑帧，按照以下顺序结算机制：ARE、重力、软降、锁定延迟、移动、旋转、硬降、暂存。
