我想要在 C++ 中实现一个文本格式化器——这最初是为实现本地化而设计的，但是按照我目前的设想也许可以完成更多任务。
localization 定义为 map<string, string>，且有一个 localization 类型的变量 lang。
格式化器被封装为一个函数（当然你可以用其他数据结构实现），它接受一个文本（string）和一个参数列表（vector<string>），并返回按照一定规则格式化后的文本。规则如下：
- 转义字符。使用 \b \t \n 代表空格、制表符、换行，同时支持 \{ \} \< \> \# \|。被转义的字符不参与后续处理。如果 \ 后的字符不为前述字符之一，则保留 \ 和其后字符。
- 格式化键。格式为 {key}，key 支持 [0-9A-Za-z]+ 并使用驼峰命名法。若 key 在 lang 中存在则转化为【对应的值递归格式化后的结果，其中参数列表复制】；否则原样不动。
- 参数。格式为 {#N}，N 为一个非负整数。若 N 越界则转化为空；否则转化为对应的参数递归格式化后的结果，其中参数列表复制。
- 带参数格式化键。格式为 {key|arg|...}，key 同上，arg 若为 #N#M... 形式则其值等于对应参数拼接的结果，否则其值为这段文本转义后的结果。转化为【对应的值递归格式化后的结果，其中参数列表依次为这些 arg 中所有非空值】。

我先提供这些。下面有两个测试问题以确保你理解了目前的需求：
1. 假设当前 lang = { "testKey": "hello {#1}" }，且参数为 { "arg0", "arg1" }，请输出 \{testKey\}\n{testKey}{foo}{testKey|arg2|#0#1} 的格式化结果。
2. 假设当前 lang = { "testKey": "{#0} {foo|#0|val\|val} {bar}", "foo" = "hello {#0|} {#1} {#2}" }，且参数为 { "a{foo}b", "c{bar}d" }，请输出 {testKey} 的格式化结果。
